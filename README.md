# Tienda de baño — Shopify Chile

Proyecto completo para lanzar una tienda online de accesorios y organización de baño
en Chile, con modelo de **stock propio / importación**, estética minimalista y foco
en conversión.

## Qué hay acá

| Carpeta | Contenido |
|---|---|
| `docs/` | El plan completo: investigación, posicionamiento, catálogo con márgenes, arquitectura de la tienda, copy, operación en Chile y plan de lanzamiento. |
| `theme/` | Secciones y snippets Liquid (Shopify Online Store 2.0) listos para subir sobre Dawn. |
| `prototipo/` | Prototipo HTML navegable del diseño (home, colección, ficha de producto). |
| `informes/` | Swipe file de anuncios y landing pages, publicado como artifact. |

## Por dónde empezar

1. `docs/00-resumen-ejecutivo.md` — la decisión de negocio en una página.
2. `docs/01-investigacion-competencia.md` — qué hacen los que venden bien y qué copiar (y qué no).
3. `docs/03-catalogo-y-margenes.md` — los números. Si esto no cierra, nada más importa.
4. `docs/09-instalacion-tema.md` — cómo bajar el diseño a Shopify.

El prototipo trae portada, colección y ficha navegables, con vista de escritorio y
móvil y anotaciones de cada decisión de conversión. El swipe file trae el desglose
de creativos de Meta, los teardowns de landing pages y los doce anuncios a producir.
Ambos son privados hasta que los compartas desde el menú de cada página.
